# 📚 Вікі-система для команди

Вебпортал для командної роботи з інтеграцією ШІ та розгортанням у Docker-контейнерах.

**Автор:** Певна Олеся | Група ТК-31

---

## 🚀 Технології

- **Backend:** Django 4.2, Python 3.11
- **База даних:** PostgreSQL 15
- **Черги задач:** Celery + Redis
- **ШІ:** Google Gemini 1.5 Flash API
- **Вебсервер:** Nginx + Gunicorn
- **Контейнеризація:** Docker + Docker Compose

---

## ⚙️ Функціональність

- ✅ Реєстрація та автентифікація користувачів
- ✅ Створення, редагування та видалення сторінок (CRUD)
- ✅ Ієрархічна структура розділів та підрозділів
- ✅ Версіонування сторінок з історією змін
- ✅ Повнотекстовий пошук по заголовку та змісту
- ✅ Розмежування прав доступу (читач / редактор / адмін)
- ✅ Асинхронне ШІ-резюмування через Google Gemini API
- ✅ Панель адміністратора Django

## 🐳 Запуск проєкту

### Вимоги
- Docker та Docker Compose
- (для macOS) Colima

### Інструкція

```bash
# 1. Клонувати репозиторій
git clone https://github.com/Lesikk8/wiki_project.git
cd wiki_project

# 2. Налаштувати змінні середовища
cp .env.example .env
# Відкрити .env і заповнити реальні значення

# 3. Запустити Docker (macOS)
colima start

# 4. Зібрати та запустити
docker-compose up --build

# 5. Застосувати міграції
docker-compose exec web python manage.py migrate

# 6. Створити адміністратора
docker-compose exec web python manage.py createsuperuser
```

### Відкрити у браузері
- Сайт: http://localhost:8080
- Адмін-панель: http://localhost:8080/admin/

## 🏗️ Архітектура

| Сервіс | Технологія | Роль |
|--------|-----------|------|
| nginx | Nginx:alpine | Reverse Proxy, статика |
| web | Python 3.11 + Gunicorn | Django застосунок |
| db | PostgreSQL 15 | База даних |
| redis | Redis 7 | Брокер для Celery |
| celery | Python 3.11 + Celery | ШІ фонові задачі |

---

## 🤖 ШІ-інтеграція

При збереженні сторінки автоматично запускається асинхронна задача Celery яка надсилає текст до Google Gemini 1.5 Flash та зберігає резюме сторінки. Користувач не чекає — все відбувається у фоновому режимі.

## 🔒 Безпека

- Секрети у `.env` файлі (не в репозиторії)
- Захист від CSRF через вбудований механізм Django
- Захист від SQL-ін'єкцій через Django ORM
- Розмежування прав доступу через `@login_required`
